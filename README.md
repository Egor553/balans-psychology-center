# Психологический центр «Баланс»

Учебный многостраничный сайт для практической работы 6. Центр, специалисты и данные вымышлены. Портреты и иллюстрация первого экрана созданы ИИ.

Страницы: главная, три специалиста, контакты с картой, тест из 60 пунктов по предоставленной методичке.

Откройте `index.html` или включите GitHub Pages для ветки `main`, каталога `/ (root)`.

Тест обрабатывает ответы только в браузере и не отправляет их на сервер. Результаты не являются диагностическим заключением. Пересечения интервалов исходной методички явно показаны.

Визуальное направление адаптировано по [Positivus Landing Page Design](https://www.figma.com/community/file/1230604708032389430/positivus-landing-page-design) (автор Olga, лицензия CC BY 4.0): белый фон, лаймовый акцент, крупная типографика, контрастные карточки и секция-аккордеон. Контент и иллюстрации сайта оригинальные для учебного проекта.
